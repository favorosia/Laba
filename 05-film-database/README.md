# Фильмы, актёры и роли — PostgreSQL + Java JDBC

Консольное Java-приложение для работы с PostgreSQL. SQL выполняется стандартным JDBC API через официальный драйвер pgJDBC; приложение разделено на слои представления, бизнес-логики и доступа к данным.

## 1. Установить и заполнить PostgreSQL

Установите PostgreSQL и убедитесь, что его служба запущена, а команды `createdb` и `psql` доступны в терминале. Из папки проекта запустите `setup-database.bat`. Скрипт создаёт базу `film_catalog`, таблицы и загружает демонстрационные данные: **40 фильмов**, актёров и назначения ролей. При повторном запуске фильмы, актёры и роли не дублируются.

Если пользователь PostgreSQL отличается от `postgres`, задайте его перед запуском скрипта:

```text
set FILM_DB_USER=имя_пользователя
```

Для проверки количества фильмов можно выполнить:

```text
psql -U postgres -d film_catalog -c "SELECT count(*) FROM movies;"
```

## 2. Собрать и запустить

Требуется JDK 17 или новее. `build.bat` скачивает официальный JDBC-драйвер 42.7.13, компилирует исходники и создаёт `film-database.jar`. Для запуска база PostgreSQL должна быть доступна.

```text
build.bat
chcp 65001
java -Dfile.encoding=UTF-8 -jar film-database.jar
```

JAR использует соседний драйвер `lib/postgresql-42.7.13.jar`, указанный в манифесте. Переменные подключения по умолчанию: `jdbc:postgresql://localhost:5432/film_catalog` и пользователь `postgres`. Пароль приложение запросит скрытым вводом в терминале. Их можно переопределить переменными `FILM_DB_URL`, `FILM_DB_USER` и `FILM_DB_PASSWORD`.

## Возможности

- Добавление и удаление фильмов и актёров.
- Изменение года выпуска фильма.
- Назначение и снятие актёрских ролей.
- Список актёров без назначенных фильмов.
- Список фильмов выбранного актёра и подсчёт его назначенных ролей.
- Вывод списков страницами с настраиваемым количеством строк.
- Проверка вводимых значений, связей и дубликатов; запросы выполняются параметризованными JDBC `PreparedStatement`.

## Устройство

`presentation` отвечает за консоль и диалог с пользователем, `service` — за правила и проверку данных, `data` — за JDBC-запросы и соединения, `domain` — за модели фильмов, актёров и ролей. Структура таблиц находится в `db/schema.sql`, демонстрационные записи — в `db/seed.sql`.
