# Учёт бытовой техники

Консольная программа для домашнего инвентаря. Данные и настройки загружаются из `data/home-appliances.bin` при запуске и сохраняются после каждого изменения и при выходе.

## Сборка и запуск

Требуется JDK 17 или новее. В Windows запустите `build.bat`, затем:

```text
chcp 65001
java -Dfile.encoding=UTF-8 -jar home-appliances.jar
```

Запускайте из папки задания: там приложение создаёт папку `data` с бинарным хранилищем.

## Возможности

- Добавление, изменение и удаление техники: название, категория, бренд, модель, дата покупки, срок гарантии в месяцах и заметка.
- Создание и переименование собственных категорий. При переименовании категория обновляется и у уже внесённых предметов.
- Поиск по названию, категории, бренду, модели и заметке.
- Сортировка по названию, категории, бренду или дате покупки.
- Настройка числа строк на странице и переход по длинным спискам.
- Текстовый импорт и экспорт UTF-8 с разделителем `;`. Кавычки позволяют сохранять значения с точкой с запятой.
- Автоматическое сохранение бинарного файла после изменений.

## Тесты

Запустите `test.bat`. Скрипт загружает JUnit Platform Console Standalone при первом запуске и выполняет JUnit 5 тесты. Maven-проект также можно проверить командой `mvn test`.

Исходники находятся в `src/ru/laba/appliances`, тесты — в `test/ru/laba/appliances`. `Appliance` описывает технику, `Inventory` управляет записями и категориями, `BinaryRepository` отвечает за бинарное хранилище, `TextExchange` — за обмен с текстовыми файлами, `ApplianceApplication` — за консольное меню.
