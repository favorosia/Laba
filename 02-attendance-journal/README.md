# Журнал посещаемости

Консольное Java-приложение читает журнал в UTF-8, считает общую статистику и посещаемость каждого студента, затем записывает отчёт в новый файл.

## Сборка и запуск (Windows)

Требуется JDK 17 или новее. Из этой папки выполните:

```text
build.bat
chcp 65001
java -Dfile.encoding=UTF-8 -jar attendance-journal.jar
```

По умолчанию программа читает `attendance.csv`, спрашивает имя отчёта (по умолчанию `attendance-report.csv`) и порядок сортировки. Аргументы запуска: `attendance.csv attendance-report.csv name`; для сортировки по пропускам вместо `name` укажите `absences`.

## Формат данных

Одна запись на строку, разделитель `;`, дата `yyyy-MM-dd`. Заголовок необязателен:

```text
student;date;status
Анна Иванова;2026-09-01;present
Борис Петров;2026-09-01;absent
```

Допустимые статусы: `present` и `absent`. Ошибки формата перечисляются с номерами строк. Отчёт содержит присутствия, пропуски и общее число записей для каждого студента, а также итоговую строку; сортировка по пропускам идёт по возрастанию.

`AttendanceRecord` представляет запись, `StudentStatistics` — результат подсчёта, `AttendanceService` выполняет чтение, расчёт и запись, `AttendanceApplication` отвечает за консольный интерфейс. Используются `List`, `Map` и сортировка из Java Collections Framework.
