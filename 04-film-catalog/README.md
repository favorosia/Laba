# Каталог фильмов с оценками

Клиент-серверное приложение на Java 17+. Сервер принимает несколько TCP-клиентов параллельно, проверяет учётные записи, хранит фильмы и пользовательские оценки, рассчитывает средний рейтинг. Сервер и клиент — отдельные запускаемые JAR.

## Сборка

В Windows запустите `build.bat`. Будут собраны `film-server.jar` и `film-client.jar`.

## Запуск

Откройте два терминала в этой папке. В первом запустите сервер:

```text
chcp 65001
java -Dfile.encoding=UTF-8 -jar film-server.jar 5050
```

Во втором запустите клиент:

```text
chcp 65001
java -Dfile.encoding=UTF-8 -jar film-client.jar 127.0.0.1 5050
```

Клиент также предложит ввести адрес и порт, если аргументы не заданы. При первом запуске создайте учётную запись, затем добавьте фильм, оцените его и проверьте средний рейтинг. Имя пользователя: 3–32 буквы/цифры или `._-`; пароль — 8–128 символов. Один пользователь может изменить свою оценку фильма повторным голосованием.

## Возможности

- Регистрация и вход; пароль хранится на сервере в виде PBKDF2-хэша с индивидуальной солью.
- Добавление фильма по названию и году, просмотр каталога, поиск по части названия.
- Оценка от 1 до 5, просмотр среднего рейтинга и числа оценок.
- Настраиваемый размер страницы и постраничный просмотр результатов.
- Бинарное хранение пользователей, фильмов и оценок на сервере в `data/film-catalog.bin`.
- Отдельные настраиваемые JUL-конфигурации в `config/`; серверные и клиентские логи записываются раздельно в `logs/`.

## Архитектура

Сервер: слой представления (`ClientHandler`, `ServerMain`), слой бизнес-логики (`CatalogService`), слой данных (`CatalogRepository`). Клиент: консольное представление (`ClientMain`), клиентский сервис (`FilmClientService`), TCP-слой (`TcpFilmConnection`). Общий пакет задаёт формат сообщений и DTO. Каждое TCP-подключение обслуживает отдельный поток из пула; изменения состояния каталога синхронизированы.

Запускайте сервер из папки проекта: хранилище и логи создаются относительно текущей папки. Для остановки сервера нажмите Ctrl+C; состояние сохраняется после регистрации, добавления фильма и каждой оценки.
