# Игровые персонажи — лабораторная работа № 5

Консольное Java-приложение для создания и управления воинами и стрелками.

## Сборка и запуск

Требуется JDK 17 или новее. В Windows запустите `build.bat`, затем:

```text
chcp 65001
java -Dfile.encoding=UTF-8 -jar game-characters.jar
```

Сборка вручную из корневой папки проекта:

```text
javac -encoding UTF-8 -d build/classes src/main/java/ru/laba/game/*.java
jar --create --file game-characters.jar --main-class ru.laba.game.GameApplication -C build/classes .
```

## Возможности

- Добавление, изменение и удаление персонажей (максимум 10).
- Просмотр списка и сводки по персонажам.
- Проведение атак с проверкой состояния бойцов и выводом результата.
- Воин наносит тяжёлый удар: сила атаки плюс сила.
- Стрелок выполняет точный выстрел: сила атаки плюс половина точности.
- Проверка ввода и диапазонов; здоровье не опускается ниже нуля.

Общие свойства и правила находятся в абстрактном `Character`; `Warrior` и `Archer` задают собственный расчёт урона. `CharacterManager` управляет коллекцией, а консольный интерфейс вынесен отдельно.
